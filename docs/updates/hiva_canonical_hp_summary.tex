\section{Motivation}
The current coefficient HiVA model fits and decodes B-spline coefficients with a duration-specific basis.  For durations
\(\mathcal D=\{6,10,15\}\), \(D_{\max}=15\), \(K=6\), and cubic degree \(p=3\), the legacy decoder uses
\(\Phi_6\), \(\Phi_{10}\), or \(\Phi_{15}\) according to the predicted duration.  This creates a failure mode: a wrong duration prediction changes both the execution horizon and the B-spline basis used to decode the same coefficient vector.

The canonical hold-pad (HP) method removes this basis-switch failure.  All samples are fitted and decoded with one canonical basis
\begin{equation}
\Phi_{\mathrm{can}}=\Phi_{15}\in\mathbb{R}^{15\times 6}.
\end{equation}
The duration head then controls only how many decoded actions are executed before re-observing.  It no longer controls which basis decodes the coefficients.

\section{Dataset: canonical HP sidecar}
For every frame-aligned training sample, the existing duration sidecar provides a ground-truth duration
\begin{equation}
d^\star\in\{6,10,15\}.
\end{equation}
The HP sidecar builds a \(D_{\max}=15\) target for each modality, then fits coefficients with the same canonical basis \(\Phi_{15}\).

\subsection{Translation target}
The raw LIBERO translation action is a relative delta.  For the real available prefix, form cumulative translation
\begin{equation}
P^\star(\tau)=\sum_{m=1}^{\tau} a^\star_{s+m-1}[0:3].
\end{equation}
Then hold after the safe duration:
\begin{equation}
\widetilde P^\star(\tau)=
\begin{cases}
P^\star(\tau), & \tau\le d^\star,\\
P^\star(d^\star), & d^\star<\tau\le D_{\max}.
\end{cases}
\end{equation}
Near episode end, if only \(R<d^\star\) real actions are available, use the real cumulative target up to \(R\) and hold from \(R+1\) onward.  This creates no artificial extra motion.

Fit coefficients by regularized least squares:
\begin{equation}
\Theta_{\mathrm{tr}}^\star
=\arg\min_{\Theta\in\mathbb{R}^{6\times 3}}
\|\Phi_{15}\Theta-\widetilde P^\star\|_2^2+\lambda\|\Theta\|_2^2.
\end{equation}

\subsection{Rotation target}
Use command-space cumulative rotation.  Compose raw LIBERO rotation-vector commands on \(SO(3)\):
\begin{equation}
R_0=I,\qquad
R_\tau=R_{\tau-1}\operatorname{Exp}(\eta a^\star_{s+\tau-1}[3:6]),
\end{equation}
then convert to cumulative rotation-vector labels
\begin{equation}
\rho^\star(\tau)=\operatorname{Log}(R_\tau).
\end{equation}
Hold \(\rho^\star\) after \(d^\star\), or after the last real available step near episode end, and fit
\begin{equation}
\Theta_{\mathrm{rot}}^\star
=\arg\min_{\Theta\in\mathbb{R}^{6\times 3}}
\|\Phi_{15}\Theta-\widetilde\rho^\star\|_2^2+\lambda\|\Theta\|_2^2.
\end{equation}

\subsection{Gripper target}
The gripper is an absolute continuous command in \([-1,1]\).  Do not cumulative-sum it.  Hold the final absolute command after the safe duration:
\begin{equation}
\widetilde G^\star(\tau)=
\begin{cases}
a^\star_{s+\tau-1}[6], & \tau\le d^\star,\\
a^\star_{s+d^\star-1}[6], & d^\star<\tau\le D_{\max}.
\end{cases}
\end{equation}
Fit
\begin{equation}
\Theta_{\mathrm{grip}}^\star
=\arg\min_{\Theta\in\mathbb{R}^{6\times 1}}
\|\Phi_{15}\Theta-\widetilde G^\star\|_2^2+\lambda\|\Theta\|_2^2.
\end{equation}

\subsection{Sidecar fields}
The HP sidecar should contain the normal coefficient fields:
\begin{lstlisting}
hiva_theta_tr_raw       [6,3]
hiva_theta_rot_raw      [6,3]
hiva_theta_grip_raw     [6,1]
duration_label          scalar in {6,10,15}
duration_class          scalar in {0,1,2}
\end{lstlisting}
It should additionally contain metadata and diagnostics:
\begin{lstlisting}
hiva_basis_mode = "canonical_hp"
hiva_target_mode = "hold_pad"
hiva_basis_dmax = 15
hiva_basis_k = 6
hiva_basis_degree = 3
hiva_real_steps
hiva_has_synthetic_tail
hiva_tail_mode in {"real", "terminal_hold"}
hiva_prefix_action_rmse
hiva_real_prefix_action_rmse
hiva_wrong_long_action_energy
hiva_tail_motion_energy
\end{lstlisting}
The summary JSON stores coefficient statistics under \texttt{coef\_stats}.  These stats must be recomputed from the HP sidecar because canonical-HP coefficients live in a different coordinate system than duration-specific coefficients.

\subsection{Diagnostics}
Two offline diagnostics are important.

\paragraph{Prefix quality.}
Decode the fitted HP coefficients with \(\Phi_{15}\), convert cumulative translation/rotation back to raw micro-actions, and measure RMSE on the safe prefix:
\begin{equation}
E_{\mathrm{prefix}}
=\operatorname{RMSE}\left(\hat A_{1:d^\star}, A^\star_{1:d^\star}\right).
\end{equation}

\paragraph{Wrong-long safety.}
For samples with \(d^\star<D_{\max}\), decode all 15 actions and measure post-duration motion:
\begin{equation}
E_{\mathrm{wrong-long}}
=\frac{1}{D_{\max}-d^\star}\sum_{\tau=d^\star+1}^{D_{\max}}
\left(\|\Delta \hat p_\tau\|_2+\|\Delta \hat r_\tau\|_2+|\hat g_\tau-\hat g_{d^\star}|\right).
\end{equation}
A good HP sidecar should have low prefix error and low wrong-long energy.

\section{Architecture: canonical decode mode}
Add a config option:
\begin{lstlisting}
hiva_basis_mode: str = "duration_specific"  # legacy default
# allowed: "duration_specific", "canonical_hp", "canonical_mt"
\end{lstlisting}

In \texttt{duration\_specific} mode, keep the legacy behavior: register one basis per duration and decode with the basis selected by predicted duration.

In \texttt{canonical\_hp} and \texttt{canonical\_mt} modes, register one canonical basis
\begin{equation}
\Phi_{15}\in\mathbb{R}^{15\times 6}
\end{equation}
and always decode a full 15-step raw action chunk:
\begin{equation}
\hat P=\Phi_{15}\hat\Theta_{\mathrm{tr}},\qquad
\hat\rho=\Phi_{15}\hat\Theta_{\mathrm{rot}},\qquad
\hat G=\Phi_{15}\hat\Theta_{\mathrm{grip}}.
\end{equation}
Duration still predicts \(\hat d\in\{6,10,15\}\), but it only controls how many prefix actions are queued for execution.  Thus, a wrong duration no longer selects a wrong basis.

\section{Training objective}
No path/tail training loss is required for the first HP implementation.  Keep the current flow-only objective:
\begin{equation}
L=L_{\mathrm{FM}}^{\mathrm{tr}}+L_{\mathrm{FM}}^{\mathrm{rot}}+L_{\mathrm{FM}}^{\mathrm{grip}}+\lambda_{\mathrm{dur}}L_{\mathrm{dur}}.
\end{equation}
The current cleaner-suffix settings can remain:
\begin{lstlisting}
hiva_duration_loss = "ce_mean"
hiva_suffix_attention = "duration_prefix"
hiva_duration_noisy_loss_weight = 1.0
\end{lstlisting}
The coefficient suffix order stays:
\begin{equation}
[\texttt{duration}][\texttt{translation coeffs}][\texttt{rotation coeffs}][\texttt{gripper coeffs}].
\end{equation}
The \texttt{duration\_prefix} attention mask is
\begin{equation}
[1,1,0,\ldots,0],
\end{equation}
so the duration token reads prefix context plus itself, while coefficient tokens read the prefix, duration token, and all coefficient tokens.

\section{Codex implementation checklist}
\begin{enumerate}
\item Add \texttt{hiva\_basis\_mode} to \texttt{configuration\_smolvla\_hiva\_coeff.py} with validation.
\item Add a canonical \(D_{\max}\times K\) basis buffer to \texttt{modeling\_smolvla\_hiva\_coeff.py}.
\item In \texttt{decode\_coefficients\_to\_raw\_actions}, if \texttt{hiva\_basis\_mode} is canonical, always decode the full \(D_{\max}\) chunk with \(\Phi_{15}\).  Do not select basis by predicted duration.
\item Keep legacy duration-specific decoding unchanged for older experiments.
\item Add a canonical-HP sidecar builder script that consumes the existing duration sidecar and writes HP coefficients plus diagnostics.
\item Update the sidecar dataset wrapper so it can validate \texttt{hiva\_basis\_mode} and optionally expose diagnostic scalars.
\item Pass \texttt{expected\_basis\_mode} from the factory into the coefficient sidecar wrapper.
\item Add \texttt{--policy.hiva\_basis\_mode} to training scripts.  Use \texttt{canonical\_hp} only with a sidecar whose \texttt{hiva\_basis\_mode} is \texttt{canonical\_hp}.
\end{enumerate}
